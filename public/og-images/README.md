# Open Graph Images

Este diretório deve conter as imagens Open Graph (OG) para compartilhamento em redes sociais.

## Especificações

- **Tamanho**: 1200x630px (padrão OG)
- **Formato**: PNG ou JPG
- **Resolução**: 2x para telas retina

## Imagens Necessárias

1. **default.png** - Logo XConstrução + background neutro (fallback para todas as páginas)
2. **home.png** - Homepage com slogan "Reinventando as relações na construção civil"
3. **xgestao.png** - xgestão inteligente com ícone de IA/dashboard
4. **legal.png** - Minimalista para páginas legais (termos, privacidade)
5. **auth.png** - Clean para login/cadastro
6. **access.png** - Gateway theme para página de acesso

## Design Guidelines

- Usar cor #333333 (marca XConstrução)
- Logo horizontal no topo ou canto
- Texto grande e legível (título da página)
- Alto contraste para visibilidade em redes sociais
- Export em 1200x630px
